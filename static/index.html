What this dashboard shows

Three domains run through the identical RFM → churn model → CLV → priority-matrix pipeline (subscription/SaaS, streaming, ecommerce/marketplace), plus a separate causal uplift analysis on a real randomized email experiment. The Cross-Domain tab tests whether churn drivers generalize across business types. The Uplift tab tests whether "at risk" and "persuadable" are actually the same customers. The Netflix domain needs a Kaggle CSV uploaded via the file picker above (optional -- everything else runs without it).

PRIORITIZE = high value + at risk (retention budget goes here first). REWARD = high value + already staying (early-access/loyalty candidates). DO NOT INVEST = low value + at risk (not worth saving). MONITOR = everything else.

Does the same framework generalize across business types?

Same pipeline, structurally different businesses. If the top driver and churn rate look similar everywhere, the "same three metrics matter everywhere" claim holds. If they diverge, segmentation needs to be domain-specific.
